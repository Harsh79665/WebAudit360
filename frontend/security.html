Security Intelligence

Passive header/TLS posture analysis and authorized active vulnerability assessments

Security Assessment Boundaries

Passive checks evaluate HTTP headers, SSL/TLS certificates, and cookie security flags without modifying target state. Passive checks do not certify that a system is bug-free or hack-proof. Active vulnerability testing requires explicit domain ownership verification via DNS TXT or HTTP challenge.

Passive Security Inspection

Inspects HSTS, Content-Security-Policy, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy, cookie attributes, and TLS certificate expiration.

Run a scan to see header posture.

Authorized Active Security Testing

OWASP ZAP non-destructive vulnerability assessment for input validation and configuration flaws. Requires verified ownership proof.

Verification Protocol:
DNS TXT: _webaudit360-challenge.<domain>
HTTP: /.well-known/webaudit360-challenge.txt
